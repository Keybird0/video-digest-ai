字幕服务

Bilibili 字幕直接读取平台接口；YouTube 原生字幕通过 Supadata 获取，不下载音频，也不做语音转写。

如何申请 API Key

打开 Supadata 控制台 ↗
  1. 注册或登录 Supadata；免费档不要求绑定信用卡。
  2. 进入控制台的 API Keys 页面，创建并复制一个 Key。
  3. 粘贴到上方输入框，然后点击页面底部的保存按钮。

免费额度与使用限制

官方规则 · 2026-08 查询
  • 免费档为每月 100 credits、限速 1 次/秒；没有单独的每日固定次数。
  • 本扩展只请求原生字幕：一次成功查询通常消耗 1 credit；字幕不可用的 206 响应也消耗 1 credit。
  • 额度不会结转到下月；用完后需等待额度刷新或升级套餐。缓存命中不会重新请求，手动“重新获取字幕”可能再次计费。
  • 仅支持公开、已结束且有平台字幕的视频；私密、登录/年龄/地区受限视频和直播可能无法获取。

套餐、额度和计费规则可能调整，请以 官方定价页 与 字幕 API 文档 的实时说明为准。
